# pochi

macOS 用の、**キーボードで選べる「このファイルを何で開く？」メニュー**。

Windows のフリーソフト「ポチエス」（esExt）にあたるものが
macOS に見当たらなかったので作りました。ファイルを渡すと、拡張子ごとに設定した候補アプリの
メニューがポップアップし、**1文字キーを押すだけ**で起動します。

```
$ pochi ~/notes/memo.md
```

```
┌──────────────────────┐
│ V  Vim (iTerm)       │   ← V を押すと即起動
│ C  VS Code           │
│ L  less で見る        │
│ ──────────────────── │
│ D  デフォルトアプリ    │
└──────────────────────┘
```

## なぜ作ったか

macOS には OpenIn のような「拡張子ごとにアプリを選ばせる」アプリがありますが、
**選択ダイアログをキーボードで操作できるかが保証されていません**。
Choosy / Velja / Finicky / Bumpr はブラウザ・リンク専用で、ファイルは扱いません。

pochi は macOS の `NSMenu` をそのまま使うので、項目ごとに 1 文字のアクセラレータが
割り当てられ、ぽちエスと同じ「ポップアップ → 1文字 → 即実行」が成立します。

## 必要なもの

- macOS
- Xcode Command Line Tools（`xcode-select --install`）

外部ライブラリは使いません。

## インストール

```bash
git clone <this repo> pochi
cd pochi
./build.sh

mkdir -p ~/bin
ln -sf "$PWD/build/Pochi.app/Contents/MacOS/pochi" ~/bin/pochi
cp -n bin/* ~/bin/

mkdir -p ~/.config/pochi
cp -n config.example.conf ~/.config/pochi/config.conf
```

`~/bin` に PATH が通っていることを確認してください。

## 設定

`~/.config/pochi/config.conf`（`-c` か環境変数 `POCHI_CONFIG` で変更可）。

```conf
[.txt .md]
v | Vim (iTerm)     | open-in-iterm vim %P
c | VS Code         | open -a "Visual Studio Code" %P
-
d | デフォルトアプリ  | open %P

[folder]
i | iTerm で開く     | open -a iTerm %P

[*]
d | デフォルトで開く  | open %P

[all]
-
r | Finder で表示    | open -R %P
```

### セクション

| 識別子 | 意味 |
|---|---|
| `[.txt .md]` | 拡張子。スペース区切りで複数指定できます |
| `[folder]` | 渡されたのがフォルダのとき |
| `[*]` | どのセクションにも該当しないとき（ぽちエスの `.*`） |
| `[all]` | すべてのメニューの末尾に追加（ぽちエスの `all`） |

### 行の書き方

| 書式 | 意味 |
|---|---|
| `キー \| 表示名 \| コマンド` | メニュー項目 |
| `表示名 \| コマンド` | アクセラレータなしの項目 |
| `-` | セパレータ |
| `{ 名前` | サブメニュー開始 |
| `}` | サブメニュー終了 |
| `#` / `;` で始まる行 | コメント |

### マクロ

| マクロ | 展開されるもの |
|---|---|
| `%P` | フルパス |
| `%D` | 親フォルダのパス |
| `%N` | ファイル名（拡張子つき） |
| `%F` | 親フォルダ名 |
| `%E` | 拡張子 |
| `%A` | ファイル名（拡張子なし） |
| `%B` | フルパス（拡張子なし） |
| `%M` | 選択された全ファイル |
| `%X` | 実行時に入力ダイアログを出す。`%X"初期値"` で初期値つき |
| `%%` | `%` そのもの |

**展開時に自動でシェルクォートされます。** ぽちエスと違い `"%P"` のように
自分で囲む必要はありません（囲むと二重になります）。

コマンドは `/bin/sh -c` で実行され、カレントディレクトリは `%D` になります。

## 動作

1. 渡されたファイルの拡張子（フォルダなら `folder`）でセクションを探す
2. 無ければ `[*]` を使う
3. `[all]` の内容を末尾に足す
4. 候補が 1 つだけなら**メニューを出さずに即実行**（ぽちエスと同じ）
5. 候補が無ければシステムのデフォルトアプリで開く

## Double Commander から使う

外部コマンドのツールバーボタンを作り、

- Command: `/Users/あなた/bin/pochi`
- Parameters: `%p0`

としてホットキーを割り当ててください。`%p0` はカーソル位置のファイル 1 つです。
複数選択をまとめて渡したいときは `%p` にして、設定側で `%M` を使います。

## 同梱のヘルパー

| コマンド | 内容 |
|---|---|
| `open-in-iterm <cmd> [args...]` | iTerm で新規ウィンドウを開いてコマンドを実行（iTerm が無ければ Terminal.app） |
| `pochi-choose-app <file>` | macOS のアプリ選択ダイアログを出して、選んだアプリで開く |

## 今のところ無いもの

ぽちエスにあって pochi にまだ無い機能です。

- メニューへのアイコン表示
- 画像 / テキストのプレビュー表示
- 第 2 設定ファイルの切り替え（Shift 起動）
- Finder のコンテキストメニューの取り込み
- `%Z`（作業フォルダ指定）— 今は常に `%D` が作業フォルダです

## 謝辞と、このソフトの位置づけ

着想は Windows のフリーソフト **「ポチエス」関連付け専用版（esExt）**（作者: サクラ 氏）から得ています。
長年お世話になったツールで、同じ発想のものが macOS に見当たらなかったため作りました。

そのうえで、本ソフトについて明確にしておきます。

- **esExt のソースコードは一切使用していません。** esExt はクローズドソースのバイナリ配布であり、
  逆アセンブル等も行っていません。本ソフトは Swift でゼロから書かれた独立した実装です。
- **esExt の配布物（実行ファイル・ドキュメント・設定サンプル）は同梱していません。**
  本リポジトリのドキュメントはすべて書き下ろしです。
- **設定ファイルの書式は esExt とは互換性がありません。** 独自に設計したものです。
- オプション用マクロ（`%P` `%D` `%N` `%F` `%E` `%A` `%B` `%M` `%X`）の割り当てのみ、
  長年 esExt を使ってきた利用者が迷わないよう、意図的に同じ文字を採用しています。
- **本ソフトはサクラ氏および「ポチエス」とは一切関係がなく、公認・提携もされていません。**

esExt の著作権は作者のサクラ氏に帰属します。素晴らしいツールをフリーで公開してくださったことに感謝します。

（配布元だった GeoCities Japan は 2019 年にサービスを終了しており、公式サイトは現存しません。）
